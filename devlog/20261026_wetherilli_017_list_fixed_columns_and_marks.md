# 017 — 목록의 열 너비 고정, ☆·짝 표시와 거르기 (`v0.3.2`)

2026-10-26 · `work/20261025-wetherilli` · wetherilli

## 한 것

- **열 너비를 고정했다** (사용자 「접힘 상태에 따라 각 열의 가로 너비가 계속 바뀐다」). 표가 자동 배치(`table-layout: auto`)라
  펼친 줄의 글자가 너비를 정했다 — 2016 년 목록에서 묶음을 하나씩 접고 펴 보니 열 너비 조합이 17 가지, 2017 년 23 가지였다(playwright 로 머리줄 `th` 너비를 쟀다).
  `table-layout: fixed` + `<colgroup>` 로 숫자 열·날짜·층준·문은 정한 폭, 분류군이 남는 폭을 가진다. 고친 뒤 세 해 모두 1 가지
- 좁은 창(900 px 아래)은 층준·문·날짜 열을 감추는 모양이라 고정 배치를 쓰지 않는다(감춘 열과 `col` 수가 어긋난다)
- **☆·짝을 목록에** (사용자 「별표 및 카운터 파트 데이터도 목록 보기에서」, 「검색할 때 태그로 필터링」).
  슬랩 번호 옆에 ☆(수만큼)와 「짝」, 격자 카드에는 꼬리표. 찾기 줄에 「☆ 별표」·「짝」 거르기 — 누르면 바로 다시 읽고, 연도·보기·묶기를 바꿔도 이어진다
- 원천 규칙은 `/starred/`·슬랩 화면과 같다(`workbook.slab_marks`) — ☆ 는 phyloserver remarks, 목록에 없는 슬랩만 엑셀.
  짝은 phyloserver 에서 읽은 슬랩은 그쪽 것만, 두 방향을 합친다

## 고친 것 — 줄 바꿈 없음 (`v0.3.3`)

- 「짝」 표시가 번호 칸 아래 줄로 내려가 줄 하나가 두 줄을 차지했다(사용자). 사용자: **「이런 리스트에서는 줄을 바꾸는 일 자체가 없어야 한다」**
- 그래서 칸마다 `white-space: nowrap` + 넘치면 `…`, 분류군·문·층준은 `title` 로 전체 글. 번호 열 10.5 → 13 rem
- v0.3.2 의 `overflow-wrap: anywhere` 가 화를 키웠다 — 1000 px 창에서 분류군이 글자마다 꺾여 줄 높이가 2,000 px 가까이 된 것도 있었다(운영 화면을 재서 보았다). 고친 뒤 901~1900 px 모두 줄 높이는 한 줄(27·39·40 px)뿐
- **휴대폰은 전제하지 않는다**(사용자) — 좁은 창 손질은 하다가 되돌렸다

## 버린 것

- `↔` 기호 — 화면 글꼴에서 `..` 로 깨져 보였다. 「짝」 글자로 쓴다
- 전경 한 장에 같이 찍힌 슬랩(`64&65`)을 짝으로 세기 — 슬랩 화면은 그것도 짝 칸에 보이지만, 거르기는 **적힌 counterpart** 만이 뜻이 맞다
- ☆ 를 표본 줄로 내기 — 목록은 슬랩 단위다. 표본 단위는 `/starred/` 에 있다
