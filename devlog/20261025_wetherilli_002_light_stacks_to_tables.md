2026-10-25 · `work/20261025-wetherilli` · wetherilli

P01 1단계. NAS 의 빛 더미 22 벌을 Slab → Specimen, Stack → Frame 테이블로 넣고, 분류 정보를 phyloserver 에서 채웠다.
라이선스는 AGPL-3.0 으로 정했다(사용자, DiaRUGA 의 `LICENSE` 원문 그대로). 폴더 이름의 `Z` 는 확대 촬영이 맞다(사용자 확인).

## 한 것

- 앱 `specimens` — `Slab`(phyloserver 꼴 `SP-2016-0052`) · `Specimen`(`SP-2016-0052-A`) · `Stack`(종류 `light` ·
  처리 `none|white_coated` · 배율 `whole|zoom` · 이름 · NAS 폴더 · `.lp`/`.ptm` · 폭·높이 · 카메라 · 촬영 시각) ·
  `Frame`(`seq` · 경로 · 빛 `x y z`, 방위각·고도는 계산값)
- `scan_light_stacks` — `.lp` 를 찾아 벌마다 Stack 하나. NAS 는 읽기만, 몇 번을 돌려도 같다(두 번째 실행 22 벌 모두 「그대로」).
  `--under "SP-2016 샘플별/6D 외"` 는 2.5 초, NAS 전체는 27 초
- `import_catalog` — phyloserver `siriuspasset` 목록 화면에서 **테이블에 있는 슬랩만** 물어 층준·분류군·문·비고와 그쪽 id 를 채운다
- `/healthz` 에 `stacks`·`frames` 수, 컷이 0 이면 degraded
- 시험 4 → 18 (`names` 5 · `lightstacks` 5 · `catalog` 3 · `healthz` +1). 대소문자 무시 찾기를 빼면 3 개, 끝의 Z 를 표본 글자로 읽게 하면 2 개가 실패하는 것을 보고 되돌렸다
- Pillow 를 `-web` 에 (컷의 폭·높이·EXIF, 2단계 축소본)

## 정한 것

- **분류 정보의 원천은 phyloserver** — 사용자가 `http://paleolab/siriuspasset/specimen_list/` 도 참고하라고 했다.
  **정정**: P01 1단계는 「엑셀에서 읽는다」였다. phyloserver 쪽이 연구실이 고쳐 가는 목록(최근 활동·사진 수·EPMA 가 붙어 있다)이고
  엑셀은 그 옛 사본이라 바꿨다. 엑셀은 파일마다 머리줄 위치·빈 칸이 달라(2016 년판은 첫 칸이 비어 있다) 읽기도 더 무르다
- **이름은 phyloserver 꼴**(`SP-2016-0052`, 네 자리) — 같은 글자로 그쪽에서 찾을 수 있어야 한다. NAS 이름은 읽을 때 바꾼다(`names.py`)
- **더미는 슬랩에 반드시, 표본에는 확실할 때만** — 대문자 글자가 있을 때만 표본을 붙인다. 소문자(`0577a`)는 표본 글자인지
  마주 조각(part/counterpart) 표시인지 몰라 이름(`label`)에만 남긴다. 사람이 붙인 표본은 다시 훑어도 떼지 않는다
- **목록에만 있는 표본은 만들지 않는다**(`52-B`·`52-C`) — 우리 테이블은 이미지가 있는 것만 갖는다
- phyloserver 에는 JSON API 가 없어 **목록 화면의 표를 읽는다**. 칸마다 `col-*` 클래스가 붙어 있어 그것으로 가르고,
  그 꼴을 시험 픽스처로 들고 있다. 주소는 `http://172.16.116.98/siriuspasset/` — 이 서버 안에서 `paleolab` 이름이 안 풀리고,
  사내망 주소는 컨테이너 안에서도 닿는다(확인)

## 버린 것

- **phyloserver 에 JSON API 를 더하기** — 더 단단하지만 운영 중인 남의 앱을 고치고 배포해야 한다. 슬랩 다섯을 묻는 지금은 화면 읽기로 충분하다.
  카탈로그 사진 반입(수천 슬랩) 때 다시 본다
- **phyloserver DB(MySQL)를 직접 읽기** — 계정이 필요하고, 남의 살아 있는 DB 를 여는 것이다(`.guides/web/data-safety.md` §14 의 정신)
- **슬랩에 표본이 하나뿐이면 그 표본으로 붙이기**(`601` → A) — 맞을 가능성이 높지만 짐작이다. 사람에게 묻는다(HANDOFF)
- **컷을 seq 별로 맞추기** — `.lp` 가 바뀌면 컷을 통째로 바꾼다. 컷에 사람이 붙인 것이 아직 없어서다. 생기면 바꿔야 한다(`save_stack` 주석)
