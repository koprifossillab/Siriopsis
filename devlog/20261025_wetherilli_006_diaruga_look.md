**확대·이동 스크립트와 축소본 서빙만** 가져오고 화면 모양은 새로 짰다. 이번에는 DiaRUGA v0.37.1 의 실제 화면을 찍어 보고 구성을 옮겼다.

## 한 것

- **바탕 틀**(`core/base.html`) — DiaRUGA 색 토큰(어둡게가 기본, 밝게), 테마 단추(시스템 → 밝게 → 어둡게, 스타일보다 먼저 정한다),
  얇게 붙는 머리줄, 자리 이름 워터마크, 오른쪽 위 **톱니 → 설정 화면**
- **목록**(`/`, `specimens/browse.py`) — DiaRUGA 목록처럼 위의 탭(채집 연도 `SP-2016` …), **접히는 묶음 표**, 묶음 줄의 합계, 맨 아래 합계, 표·격자 전환.
  묶음은 **번호**가 기본: 백 개 단위로 접고 안에 **NAS 의 열 개 폴더 이름**(`SP-2016(101~110)`) 가름줄 — 사람이 자료를 그 폴더로 찾아 왔다(사용자).
  **층준**으로도 묶는다: phyloserver 의 층준은 손글씨(`6.2~6.3`·`~7.3`·`scree`·빈칸 절반)라 고치지 않고 첫 수를 0.1 m 구간으로 내려 묶기만 한다
- **슬랩 화면** — DiaRUGA 슬라이드 화면처럼 머리·한 줄 요약·사진 격자, 표본마다 끊는다
- **더미 화면** — DiaRUGA 시야 화면 구성: [왼쪽: 화면 조정·이 슬랩의 더미 격자·키] [가운데: 검은 판 + 떠 있는 「보기」 도구(맞춤·전체 화면·SD/HD) +
  원본 화소 기준 배율 %, 아래 컷 카드 줄과 ‹ › ] [오른쪽: 빛 방향 판·정보·같은 묶음]
- **로고** — 사용자가 만든 것(`docs/assets/logo/`, 할키에리아 골편 여덟 장이 시리우스의 반짝임). 머리줄 마크(21px 에서는 후광을 뺐다)·탭 아이콘
- **대기 화면** — DiaRUGA 234·235 를 옮겼다(탭마다 한 번, 누르면 걷힘, 끝 장면에서 정지 그림). 받은 것이 **투명 배경 webp** 두 벌이라
  테마 바탕 위에 얹고 테마에 맞는 벌을 고른다 — DiaRUGA 는 GIF 라 바탕색을 박아야 했다
- **설정 화면**(`/system/`) — 지금 판, 만든 곳, 자료 현황, 자리, **판 이력**(CHANGELOG.md 를 그대로 읽는다 — 적는 곳은 하나, devlog 링크는 GitHub 으로)
- **바닥글** — 판 · 자료 출처 극지연구소 고생물진화연구실 · 만든이 극지연구소 이승찬 · AGPL-3.0 (사용자). 더미 화면은 사진이 창 높이를 다 쓰므로 오른쪽 칸 아래에
